# FocusGate

A personal distraction blocker for Windows, built for studying on the PC.

## Idea

When the computer starts, FocusGate asks one question: **full access** or **work mode**?

- **Full access:** the app closes itself and doesn't use any resources until the next boot.
- **Work mode:** only apps on an allowlist can run. Everything else (games, leisure apps) is closed. Websites like YouTube ask "study or leisure?" before a video plays, while music keeps working.

## Principles

- **Deny by default:** you choose which apps are allowed during setup, and everything else is blocked.
- **Local only:** no account, no internet, no data.
- **Friction on purpose:** in strict mode, the only way out of work mode is to restart the PC.
